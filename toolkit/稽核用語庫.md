# 稽核用語庫

撰寫結構：**現場事實＋管理問題＋風險或改善要求**

範例：
> 經現場查核，發現丸子於製程作業期間大量掉落地面，顯示產品防護及製程作業衛生管理未落實，存在產品污染風險。請立即管制掉落產品，依不合格品管制程序辦理，並檢討掉落原因及改善措施，以防止類似情形再次發生。

## 一、現場稽核常用專業用語

| 使用情境 | 稽核老師用語 |
|---|---|
| 發現現場髒污 | 現場環境衛生維護未臻完善。 |
| 發現產品掉落地面 | 製程作業期間產品防護措施未落實，存在污染風險。 |
| 發現設備髒污 | 設備清潔維護未落實，請依規定執行清潔並確認清潔效果。 |
| 發現器具未清潔 | 作業器具清潔及衛生管理未落實。 |
| 發現人員未戴帽 | 作業人員未依規定穿戴防護用品。 |
| 發現人員洗手不確實 | 作業人員手部清潔及消毒程序未確實執行。 |
| 發現生熟食混放 | 生熟食區隔管理未落實，存在交叉污染風險。 |
| 發現原料落地 | 原物料離地存放及污染防範措施未落實。 |
| 發現垃圾未清理 | 廢棄物清除及環境衛生管理未落實。 |
| 發現排水溝髒污 | 排水設施清潔維護未落實。 |
| 發現病媒或鼠跡 | 病媒防治及監測管理應加強。 |
| 發現冷藏溫度異常 | 冷藏溫度管制未符合內部規定，請確認異常原因並採取改善措施。 |
| 發現紀錄漏填 | 相關作業紀錄填寫不完整，請依規定確實執行並留存紀錄。 |
| 發現相同缺失重複發生 | 相同缺失再次發生，顯示既有改善措施或預防再發機制仍有不足。 |

## 二、缺失開立與改善追蹤用語

**1. 開立缺失**
- 經現場查核，發現上述作業未依規定執行。
- 現場衛生管理措施未落實，請相關單位檢討改善。
- 該作業存在食品污染風險，請立即採取必要管制措施。

**2. 要求立即改善**
- 請立即改善現場異常情形，並落實後續衛生管理。
- 請立即清除污染源，並確認相關區域及接觸面之清潔狀況。
- 請依不合格品管制程序辦理，避免異常產品流入後續製程。

**3. 要求限期改善**
- 請於規定期限內完成改善，並提供相關佐證資料。
- 請針對缺失原因提出改善措施，並落實預防再發。
- 請評估現行作業方式及管制措施之適切性，提出具體改善方案。

**4. 複查與結案**
- 經現場複查，確認改善措施已完成，符合要求。
- 經複查，原缺失仍未改善完成，請持續改善並於期限內重新提出佐證。
- 經確認改善措施已執行，惟仍須持續追蹤其執行成效。

**5. 重複缺失**
- 經查核發現相同缺失再次發生，請重新檢討根本原因。
- 原改善措施未能有效防止缺失再發，請提出具體矯正及預防措施。
- 請相關單位加強日常自主檢查，並由權責主管確認執行情形。
