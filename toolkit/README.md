# 衛生缺失工具包（草稿，尚未販售）

安安的建議：要給朋友或客戶時，賣的是「工具包」（提示詞＋使用說明），不是分享這個工具本身。
這個資料夾先收集工具包的素材，正式販售前要再整理，並依課程流程確認。

| 檔案 | 內容 |
|---|---|
| `缺失類別清單.md` | 15 個缺失類別與分類範圍 |
| `缺失等級判定規則.md` | 一般／限期改善／重大缺失的判定條件、考量因素、判定原則與輸出格式 |
| `稽核用語庫.md` | 現場稽核常用專業用語、缺失開立與改善追蹤用語、撰寫結構 |
| `稽核老師分析提示詞.md` | 「產生分析」用的提示詞，可以貼到自己的 Claude 使用 |

使用時請勿填寫員工或任何人的姓名、電話、地址、身分證字號，改用「品管人員」「作業員 A」等代稱。
