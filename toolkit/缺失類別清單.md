# 缺失類別清單

| 編號 | 缺失類別 | 常見缺失內容 |
|---|---|---|
| 01 | 人員衛生 | 未依規定穿戴工作服、工作帽，手部清潔不確實、個人衛生不佳 |
| 02 | 環境衛生 | 地面髒污、積水、牆面污垢、天花板有污染 |
| 03 | 設備衛生 | 生產設備殘留物、設備清潔不完全、設備表面髒污 |
| 04 | 器具與容器衛生 | 刀具、周轉箱、容器清潔不完全或未妥善存放 |
| 05 | 清潔與消毒管理 | 未依規定清潔消毒、清潔頻率不足、消毒紀錄不完整 |
| 06 | 病媒防治 | 發現蚊蠅、蟑螂、鼠跡，捕蟲燈或防蟲設施異常 |
| 07 | 原物料衛生 | 原料受到污染、原料落地、原料未妥善覆蓋 |
| 08 | 製程衛生 | 作業過程污染、作業區衛生不佳、生熟食未適當區隔 |
| 09 | 交叉污染防治 | 生熟食交叉接觸、不同原料混放、清潔工具混用 |
| 10 | 儲存與倉儲衛生 | 物料堆放不當、未離地離牆、儲存環境不潔 |
| 11 | 洗手與消毒設施 | 洗手設備故障、洗手用品不足、消毒設施未正常運作 |
| 12 | 廢棄物管理 | 垃圾未及時清除、廢棄物容器未加蓋或清潔不佳 |
| 13 | 排水與排污衛生 | 排水溝堵塞、積水、污水溢流或異味 |
| 14 | 廠房設施衛生 | 門窗破損、紗網損壞、設施有積垢或不易清潔 |
| 15 | 工作服與防護用品 | 工作服髒污、工作帽未完整包覆頭髮、防護用品使用不當 |
| 16 | 化學品管理 | 清潔劑未妥善標示、消毒劑存放不當、化學品污染風險 |
| 17 | 溫度與環境管制 | 冷藏冷凍環境異常、環境溫度紀錄未依規定執行 |
| 18 | 衛生紀錄管理 | 清潔紀錄未填寫、巡檢紀錄不完整、紀錄與實際作業不符 |
| 19 | 外來人員與訪客管理 | 訪客未穿戴防護用品、進入管制區未依規定執行衛生程序 |
| 20 | 其他衛生缺失 | 無法歸入上述類別的其他衛生問題 |

## 使用建議

- 先看「常見缺失內容」再選類別，讓每個人用同一套標準。
- 一筆缺失只選一個最主要的類別；分不進去的選「20 其他衛生缺失」。
- 「缺失類別」是屬於哪一類；「缺失等級」（一般／限期改善／重大）是嚴重程度，由品管判定，兩者不同。
