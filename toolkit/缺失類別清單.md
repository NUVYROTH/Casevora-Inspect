# 缺失類別清單

| 編號 | 缺失類別 | 分類範圍 |
|---|---|---|
| 01 | 人員衛生管理 | 個人衛生、健康管理、手部清潔、工作服帽、口罩及防護用品穿戴 |
| 02 | 環境與廠房衛生 | 地面、牆面、天花板、門窗、廠區環境、照明及通風 |
| 03 | 設備與器具衛生 | 生產設備、刀具、容器、周轉箱、器具清潔、維護及存放 |
| 04 | 清潔與消毒管理 | 清潔消毒作業、清潔頻率、消毒劑使用、清潔工具管理及效果確認 |
| 05 | 病媒防治管理 | 蚊蠅、蟑螂、鼠害、防蟲設施、捕蟲燈及病媒監測 |
| 06 | 原物料與產品衛生 | 原物料、半成品、成品的污染防止、覆蓋、接觸面及衛生保護 |
| 07 | 製程與交叉污染防治 | 生熟食區隔、作業動線、過敏原、異物防止及製程衛生 |
| 08 | 倉儲與溫度管理 | 冷藏冷凍、溫度管制、物料堆放、離地離牆、效期及儲存環境 |
| 09 | 洗手與衛生設施管理 | 洗手台、消毒設備、洗手用品、廁所、更衣室及相關衛生設施 |
| 10 | 廢棄物與排水管理 | 垃圾清除、廢棄物容器、排水溝、積水、污水及異味 |
| 11 | 化學品管理 | 清潔劑、消毒劑及其他化學品的標示、存放與使用 |
| 12 | 外來人員與區域管制 | 訪客管理、進出管制、區域區隔及進入作業區的衛生要求 |
| 13 | 衛生紀錄與制度管理 | 清潔紀錄、巡檢紀錄、溫度紀錄、衛生程序及教育訓練紀錄 |
| 14 | 其他衛生缺失 | 無法歸入以上類別的缺失 |

## 使用建議

- 先看「分類範圍」再選類別，讓每個人用同一套標準。
- 一筆缺失只選一個最主要的類別；分不進去的選「14 其他衛生缺失」。
- 「缺失類別」是屬於哪一類；「缺失等級」（一般／限期改善／重大）是嚴重程度，由品管判定，兩者不同。
